## ETL

![C4](./img/c4.png)

В архитектуру системы добавляется модуль *ETL* на основе *Apache Airflow*. В его задачи входит собирать данные из БД CRM и БД API, и, предварительно переработав, загружать в отдельную таблицу для очтетов.
