# Разработка сервиса отчётов

## Объектное хранилище

![C4](./img/c4.png)

Для хранения отчетов, логов и других файлов используется *MinIO*, а доступ к файлам отчетов организуется через *CDN*. В данной реализации используем эмуляцию *CDN* при помощи NGinx со включенным кэшированием статических файлов.
