# Разработка сервиса отчётов

## ETL

![C4](./img/c4.png)

В архитектуру системы добавляется модуль *ETL* на основе *Apache Airflow*. В его задачи входит собирать данные из БД CRM и БД API, и, предварительно переработав, загружать в отдельную таблицу для очтетов.

## Объектное хранилище

Для хранения отчетов, логов и других файлов используется *MinIO* - высокопроизводительное решение для хранения объектов. MinIO предоставляет S3-совместимое API и веб-консоль для управления бакетами и файлами.

### Бакеты MinIO

- `reports` - для хранения сгенерированных отчетов
- `logs` - для хранения логов системы
- `temp` - для временного хранения файлов
